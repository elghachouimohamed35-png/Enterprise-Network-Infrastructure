# Enterprise Network Infrastructure | Cisco Packet Tracer

**Design, Configuration & Implementation of a Multi-Site Enterprise Network**

A hands-on networking project developed using Cisco Packet Tracer to simulate an enterprise network infrastructure. This project demonstrates practical knowledge of routing, switching, network segmentation, redundancy, and essential network services.

## 📸 Network Topology

![Enterprise Network Topology](topology.png)

## 🎯 Project Objectives

- Design and simulate a multi-site enterprise network.
- Configure dynamic routing between network devices.
- Implement VLANs for network segmentation.
- Enable inter-VLAN communication.
- Improve network availability through redundancy mechanisms.
- Configure essential network services.
- Develop troubleshooting and network administration skills.

## 🛠️ Technologies & Protocols

| Technology | Purpose |
|---|---|
| Cisco Packet Tracer | Network design and simulation |
| OSPF | Dynamic routing |
| VLANs | Logical network segmentation |
| Inter-VLAN Routing | Communication between VLANs |
| HSRP | Gateway redundancy and high availability |
| STP | Prevention of Layer 2 switching loops |
| EtherChannel | Link aggregation and redundancy |
| VTP | VLAN management |
| DHCP | Automatic IP address assignment |
| VPN | Simulated secure connectivity between sites |

## 🏗️ Network Components

- Cisco routers and switches
- End-user PCs and network devices
- Servers and network services
- IP phones and wireless devices
- Interconnected network segments and sites

## ⚙️ Key Features

- Structured enterprise network topology
- Dynamic routing configuration using OSPF
- VLAN creation and segmentation
- Inter-VLAN routing
- Redundant gateway configuration using HSRP
- Switching loop prevention using STP
- Link aggregation using EtherChannel
- Automatic IP addressing through DHCP
- Network connectivity testing and troubleshooting

*Features listed above should correspond to the configurations implemented in the supplied Packet Tracer file.*

## 🚀 How to Run the Project

1. Install Cisco Packet Tracer.
2. Clone or download this repository.
3. Open `Enterprise-Network-Infrastructure.pkt` in Cisco Packet Tracer.
4. Inspect the network topology and device configurations.
5. Test connectivity between devices using ping and other available diagnostic commands.

## 🧪 Testing & Validation

The network can be evaluated through:

- End-to-end connectivity tests.
- IP addressing and DHCP verification.
- OSPF neighbor and routing table checks.
- VLAN and trunk configuration checks.
- Inter-VLAN communication tests.
- Redundancy and switching behavior verification.
